## Customizing

`blueprint/` is shared by every copy. Improvements that would help every copy are made in the base itself, where it is developed. Changes for one person never go in `blueprint/`; they go in `custom/`:

- a file in `custom/rules/` with the same name as a base rule replaces it (`custom/rules/links.md` replaces `blueprint/rules/links.md`);
- your own rules are files named `my-*.md` in `custom/rules/`;
- to leave a base rule out, add a line `rules/<name>` to `custom/disable`: the rule stays in `blueprint/`, untouched, but no longer reaches `AGENTS.md`, and updates cannot bring it back;
- rules that hold in every folder, not only in this repository, are files named `my-*.md` in `custom/global/rules/`, and such skills are folders named `my-*` in `custom/global/skills/`. They go in `GLOBAL.md`, which `blueprint/scripts/global.sh` takes to each agent outside the repository, and also at the end of `AGENTS.md`, so they hold here even where `global.sh` has not run. Where a rule or skill goes depends on where it applies: only in this repository, in `custom/rules/` or `custom/skills/`; only in another repository, in that repository's own `AGENTS.md` and skills, never in `custom/global/`, which loads in every session everywhere; in any folder, in `custom/global/`. Within `custom/global/`, a rule is for what every session needs (how to answer, how to commit), and a skill for what is needed only when doing something specific (writing React components, say): a rule is read whole in every session, while a skill takes only its name and description until it is needed.

Besides rules, `custom/skills/` holds the owner's skills (see Skills), a file in `custom/templates/` replaces the base template with its name in `blueprint/templates/` (`journal.md` is the one for each day's note, which `blueprint/scripts/today.sh` creates), `custom/git-hooks/commit-msg`, if present, is run with the commit message and can reject it, and `custom/git-hooks/test-*.sh` run with the other tests. Anything else in `custom/` makes the check fail. `AGENTS.md` and `GLOBAL.md` are generated by `blueprint/scripts/rules.sh`. Never edit them by hand.
