## Memory

Agents keep no private memory about the owner or this repository: what they learn goes where every agent can read it and the owner can review it. How the owner wants things done becomes a proposed rule in `custom/rules/my-*.md`; facts go in the note where they belong. If an agent's tool has a memory of its own, turn it off for this repository, or keep in it only what concerns the tool itself.

Before proposing a rule, say when it applies and check that it holds beyond the case that prompted it: what happened once, or only in one kind of task, is not a rule for everything. Scope it to that kind of task, or leave it out.
