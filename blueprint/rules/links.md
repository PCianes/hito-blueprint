## Links

Every note is born linked from another (its folder's `README.md`, a project, or another note), except where its path already finds it: a journal day by its date, a source by its author. Use relative Markdown links, never wiki-links, so they work in any viewer and for any agent. The check fails if a relative link points to nothing, so when a note moves (to `archive/`, say), fix the links to it and in it.
